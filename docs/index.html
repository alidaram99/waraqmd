Markdown, opened right — in English or Arabic, on your laptop or your phone.

Waraq (ورق, "paper") is a Markdown reader and editor that installs like an app and can become the thing your device opens .md files with — instead of Notepad, a blank tab, or nothing at all.

Direct answer: Waraq is a free, installable, offline web app (PWA). Install it once from your browser, then it can open .md/.markdown/.mdx/.txt/.json/.yaml/.log files you double-click (Windows, ChromeOS, Android) or share to it (Android), render Mermaid diagrams and KaTeX math, and automatically get Arabic and English paragraphs — even mixed in one document — reading the right direction. No account, no upload, no payment.

Built for files agents and people both produce

Mermaid & KaTeX

Fenced ```mermaid diagrams and $math$ render inline — loaded only when a document actually uses them, so plain notes stay fast.

Tables, task lists, front matter

GitHub-flavored tables and - [ ] task lists render natively; YAML front matter shows as a collapsible metadata card, not a stray code block.

Automatic Arabic/English direction

Every paragraph, heading, list item and table cell gets its own reading direction from the browser's Unicode bidi algorithm — no manual RTL toggle, no whole-document setting.

Large files stay smooth

Big reports and logs are rendered section by section as you scroll, instead of freezing the tab on open.

Edit and save back

On Chromium browsers, Waraq writes straight back to the same file via the File System Access API — no download-and-replace dance.

Never leaves your device

No server, no account, no telemetry. Files are read, rendered and saved locally; exporting standalone HTML inlines everything into one file.

Make Waraq your default .md app

  1. Open the Waraq app in Edge or Chrome.
  2. Click the install icon in the address bar (or menu ⋯ → Apps → Install this site as an app).
  3. Right-click any .md file → Open with → choose Waraq → check Always use this app.
  4. Or: Settings → Apps → Default apps, search .md, and pick Waraq there.

Windows ships Notepad as the out-of-the-box default for .md; this replaces that association with Waraq, for your account only.

  1. Open the Waraq app in Chrome on your phone.
  2. Tap the ⋮ menu → Install app (or "Add to Home screen").
  3. From a file manager, tap a .md file and choose Waraq, or use Share → Waraq from any app.

This relies on Chrome's WebAPK file-handling support, which can vary slightly by device and Android version — if the "Open with" list doesn't show Waraq yet, try reinstalling the app once after this page's first visit.

FAQ

How do I make Waraq my default app for .md files on Windows?

Open the Waraq app in Edge or Chrome, install it from the browser's install icon, then right-click any .md file, choose Open with, pick Waraq, and check "Always use this app". You can also set it from Settings → Apps → Default apps by searching .md.

Does Waraq work as the default Markdown app on Android?

Yes, after installing it from Chrome ("Add to Home screen" / Install app). Chrome registers installed PWAs as file handlers on Android through a WebAPK. You can also share a file to Waraq directly from the share sheet of another app.

Does Waraq work on iPhone or Safari?

Waraq runs in Safari and you can open or paste files manually, but Apple's WebKit does not support the File Handling API, so Waraq cannot be registered as the default .md app on iOS/iPadOS today.

Does Waraq upload my files anywhere?

No. Waraq reads and writes files on your device using the browser's File System Access API or a local file picker. Nothing is uploaded to render, save, or export a file.

Does Waraq handle Arabic and mixed Arabic/English text?

Yes. Every paragraph, heading, list item and table cell gets automatic direction from the browser's own bidi algorithm, so Arabic and English can sit in the same document, even the same line, and each renders the correct way. One known limit: Mermaid diagram labels in Arabic script may not shape correctly — a Mermaid limitation, not Waraq's bidi handling.

Is Waraq free?

Yes, v0.1.0 is free and open source (MIT). It runs entirely in your browser with no account and no server component. See RESEARCH.md for what paid features might look like later.
